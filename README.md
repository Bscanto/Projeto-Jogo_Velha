# Projeto Jogo da Velha

Este é um jogo de Tic-Tac-Toe (Jogo da Velha) criado com HTML, CSS e JavaScript.

## Funcionalidades

- Entrada de nomes para os dois jogadores
- Tabuleiro interativo 3x3
- Alternância de turnos entre X e O
- Detecção de vencedor e empate
- Placar de vitórias e empates
- Reset do tabuleiro e reinício do jogo
- Layout responsivo e moderno

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Preencha os nomes dos jogadores.
3. Clique em **Iniciar Jogo**.
4. Toque nas células para jogar.
5. Use **Reiniciar Tabuleiro** para começar uma nova partida mantendo o placar.
6. Use **Novo Jogo** para reiniciar completamente os jogadores e o placar.

## Estrutura de arquivos

- `index.html` - marcação do jogo
- `assets/css/style.css` - estilos visuais e responsivos
- `assets/js/index.js` - lógica do jogo e controle de fluxo

## Tecnologias

- HTML
- CSS
- JavaScript

## Observações

O projeto foi criado para ser simples e fácil de usar. Basta abrir o `index.html` no navegador para jogar imediatamente.
